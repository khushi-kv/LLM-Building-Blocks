# llm-building-blocks

Core LLM application patterns in Python, built from scratch.

## Contents

| Folder | What it does |
|---|---|
| `terminal-chat/` | Command-line chat with validated message history |

## Setup

```bash
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
cd terminal-chat
python main.py
```

## Stack

Python, Pydantic
